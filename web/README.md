# 마법학교 아르피아 온라인 (원작 시스템 복원 웹 프로토타입)

쿼터뷰 턴제 RPG 웹게임. 마법학교를 배경으로 파티(주인공 + 펫)를 꾸려 필드 몬스터와
ATB 턴제 전투를 벌이고, 레벨업·전직·장비·상점·펫 훈련을 플레이한다.

> **2026-08 개편**: 나무위키 「마법학교 아르피아」 정설에 맞춰 시스템을 재구성했다.
> 설계 기준 문서: `../Documents/아르피아 시스템 DB.md`
> - 속성: 4종(불/물/바람/흙) → **원작 3종 불꽃 > 얼음 > 대지**
> - 전직: 견습 → 초보 → 숙련 → 마도사 → 대마도사 (Lv 1·10·20·30·40)
> - 턴: 단순 속도 정렬 → **ATB 대기 게이지**
> - 상태이상 9종, 펫 호감도·스킬 훈련 추가
>
> 스택: Next.js App Router + TypeScript + Tailwind CSS v4.
> 아래 실행 방법 중 개발 서버(B)를 권장한다. `out/` 정적 빌드는 이번 개편분이 미포함이니
> `npm run build` 로 다시 생성한다.

---

## 1. 실행 방법

### 방법 A — 미리 빌드된 정적 파일 바로 실행 (가장 간단)

압축을 푼 뒤 `out/` 폴더가 이미 들어있습니다. 아래처럼 로컬 서버로 열면 바로 플레이할 수
있습니다. (브라우저 보안 정책상 `index.html`을 더블클릭해서 여는 방식은 일부 브라우저에서
정상 동작하지 않을 수 있어, 로컬 서버 실행을 권장합니다.)

```bash
cd out
npx serve .
# 또는
python3 -m http.server 4173
```

그 다음 브라우저에서 `http://localhost:3000` (혹은 표시된 포트)로 접속하세요.

### 방법 B — 개발 서버로 실행 (코드 수정하며 플레이)

```bash
npm install
npm run dev
```

`http://localhost:3000` 접속. 코드를 수정하면 즉시 반영됩니다.

### 방법 C — 직접 다시 빌드하기

```bash
npm install
npm run build   # out/ 폴더에 정적 파일이 새로 생성됩니다
```

## 2. 조작 방법

- 이동: `방향키` 또는 `WASD` (모바일 화면에서는 우하단 D-Pad 사용)
- NPC와 대화: 가까이 다가가면 하단에 안내가 뜨며 `E` 키 또는 NPC를 클릭
- 몬스터와 접촉하면 자동으로 턴제 전투가 시작됩니다
- 우상단 아이콘: 가방 / 내 정보 / 파티 / 환경설정

### 조사 근거 (기획 11번)

"아르피아"는 실제로 **마법학교 아르피아(2007년 출시, J-Interactive 개발, 야후코리아를 통해
서비스되다 2012년 서비스 종료)** 라는 턴제 RPG로 확인되었습니다. 속성별 마법학교(불/얼음/대지/
번개), ATB식 턴 진행, 펫 애정도 시스템 등 특징을 조사해 이번 초안의 방향을 잡는 데 참고했습니다.
다만 실제 화면/그래픽 자료가 온라인에 거의 남아있지 않아(장기간 서비스 종료된 게임), 저작권이
있는 원본 그래픽을 그대로 재현하는 대신 "같은 장르/시대의 느낌"을 살린 오리지널 디자인으로
제작했습니다.

### 추가 고증 (동인 리메이크 `ReArpia` 기획서 반영)

연결해주신 `아르피아 복원` 폴더에서 실제 원작 개발자분이 작성하신 `Documents/전투 기획서.md`를
확인했습니다. 이 문서는 `ReArpia`(엔씨소프트 `마법학교 아르피아`의 동인 리메이크, 언리얼엔진
기반 실시간 전투로 재설계 중)의 기획서였는데, 원작 `마법학교 아르피아`의 전투 방식도 함께
정리되어 있어 이번 초안에 다음을 반영/수정했습니다.

- **원작 전투 메뉴 고증**: 기본공격/스킬/아이템/한 턴 넘기기/도망가기 — 본 초안의
  공격/스킬/물약·도구/방어/도망 메뉴 구성이 원작과 거의 일치함을 확인했습니다.
- **속성 상성 순환 구조 반영 및 버그 수정**: 원작은 "불꽃 > 얼음 > 대지 > 불꽃"의 3속성
  순환 상성이었습니다. 본 게임은 기획 요청대로 불/물/바람/흙 4속성이므로, 이 순환 상성 개념을
  "불 → 바람 → 흙 → 물 → 불" 4속성 순환으로 확장 적용했습니다. (참고로 최초 초안에서
  `흙` 속성이 자기 자신에게 강하다고 되어있던 버그가 있었는데, 이번에 함께 수정했습니다.)
- **종족 속성 보너스 고증**: "캐릭터는 자신의 속성과 같은 마법에 추가 공격력을 가진다"는
  원작 설계를 이미 `ELEMENT_META.leanStats`로 구현하고 있었음을 재확인했습니다.
- 원작은 턴제(모든 스킬 재사용 대기시간 동일), `ReArpia`는 실시간 전투로 방향을 틀었다는 점도
  확인했는데, 이번 요청은 명시적으로 "턴제 RPG"였으므로 원작 방식(턴제)을 그대로 따랐습니다.

out/                      미리 빌드된 정적 웹게임 (바로 실행 가능)

## 5. 알려진 제한사항 / 다음 단계 제안

- **펫 디자인**: 말씀하신 대로 실제 디자인안은 아직 없어 임시 아이콘/스탯만 넣었습니다. 디자인이
  나오면 `lib/player-factory.ts`의 `createStarterPet`과 `public/images`만 교체하면 됩니다.
- **스킬/몬스터 밸런싱**: 현재 수치는 전투가 "돌아가게" 만든 임시값입니다. 실제 기획이 정해지면
  `lib/mock-data.ts`의 `SKILLS`/`MONSTERS` 값만 조정하면 됩니다.
- **파티 동료(3·4번 슬롯)**: UI 자리만 마련해두었고 실제 합류 로직은 없습니다.
- **하우징 / 콜로세움 대전**: 존 자체와 안내 NPC까지는 배치했지만 실제 기능은 "추후 구현 예정"
  안내만 표시됩니다.
- **사운드**: 설정 화면에 음량 슬라이더는 있지만 실제 오디오 파일은 없습니다.
- **아트**: 전부 코드로 생성한 벡터 아이콘입니다 — 최종 비주얼(캐릭터 스프라이트, 타일 아트 등)은
  별도 작업이 필요합니다.
