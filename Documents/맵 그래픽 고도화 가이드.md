# 마을 맵 그래픽을 위치브룩(Witchbrook)급으로 올리는 가이드

> 현재 상태: `web/` 마을은 **손으로 그린 SVG 아이소메트릭 엔진**.
> z높이·오클루전(건물 뒤로 걸어가면 가려짐)·충돌·카메라 추적은 이미 동작.
> 병목은 **엔진이 아니라 아트 에셋**이다. 아래는 에셋을 채우는 방법.

## 2. 적용 방법 — 현재 코드에 붙이기

### 현재 구조
| 파일 | 역할 |
|---|---|
| `web/lib/iso.ts` | 2:1 다이메트릭 투영(`isoToScreen`), `TileKind` / `PropDef` 타입, `TILE_COLORS` |
| `web/components/game/iso-sprites.tsx` | **모든 스프라이트가 SVG 손그림.** `renderProp(PropDef)` 가 `kind` → 컴포넌트 매핑. `IsoChara` = 캐릭터 |
| `web/components/game/iso-world.tsx` | 지면 타일 렌더 + **깊이정렬**(화면 y) + 카메라 추적/clamp + 건물 그림자 |
| `web/lib/maps.ts` | `village.tileAt(x,y)` = 지면, `village.props[]` = 오브젝트 배치, `village.blockers[]` = 충돌 |
| `web/lib/game-state.tsx` | `blockedAt()` = 이동 시 건물 충돌(axis-slide) |

### 라스터(PNG) 에셋으로 교체 순서

1. **에셋 규격 통일**
   - 지면 타일: 다이메트릭 2:1, 가로폭 = `ISO_TILE_W`(64)의 배수. (예: 128×64, 256×128)
   - 건물/오브젝트: 투명 배경 PNG. **발밑 앵커 픽셀 좌표**를 파일별로 기록 (예: `magic-hall.png` 앵커 = (128, 300)).
   - 캐릭터: 스프라이트 시트. 방향(4 또는 8) × 걷기 프레임(4~8). 앵커 = 발.
   - `image-rendering: pixelated` 유지 → 확대해도 도트 선명.

2. **지면 교체** (`iso-world.tsx`)
   - `TILE_COLORS` → `TILE_SPRITES: Record<TileKind, string>` (PNG 경로).
   - 지면 `<polygon>` → `<image href={TILE_SPRITES[kind]} x=… y=… width={ISO_TILE_W} height={ISO_TILE_H*배수}/>`.
   - 타일도 y기준으로 그려서 높이 있는 타일(절벽 등) 대응.

3. **오브젝트 교체** (`iso-sprites.tsx`)
   - `PropDef` 에 `anchor?: {x,y}` (발밑 오프셋) 추가.
   - `renderProp()` 을 `<image href={PROP_SPRITES[p.kind]} x={-anchor.x} y={-anchor.y} width height/>` 로 단순화.
   - `iso-world.tsx` 의 `sortY` 계산은 그대로(앵커/footprint 중심 기준).

4. **캐릭터 교체** (`IsoChara`)
   - `<image>` + `viewBox`/`clipPath` 로 시트에서 프레임 1칸 선택.
   - 방향 = `state.facing`, 프레임 인덱스 = `moving` 이면 rAF 카운터로 순환.
   - NPC 도 같은 방식(역할별 시트 or 팔레트 스왑).

5. **그대로 두는 것**: 깊이정렬, 카메라, 충돌(`blockers` / `blockedAt`), 포탈/게이트, 미니맵.
   - `blockers` 좌표만 새 건물 footprint 에 맞게 재조정.

6. **성능**: `<image>` 수십~수백 개면 느려질 수 있음 → 에셋을 **아틀라스 1장**으로 합치고
   CSS `background-image` + `background-position`, 또는 canvas 렌더로 전환.

7. **폴백 유지**: `GameMap` 에 `assets?: 'svg' | 'raster'` 플래그를 두고
   `iso-world` 에서 분기하면, 라스터 에셋이 부족한 맵은 지금 SVG로 계속 렌더 가능.

### 현실적 진행 순서
1. **Kenney 아이소 팩**으로 지면 + 건물 먼저 교체 → 전체 톤 확인
2. 부족한 건물/소품만 **Aseprite로 직접** 그리거나 **Pixellab**로 생성 후 보정
3. 캐릭터 시트 제작(또는 커미션)
4. 커미션은 최종 폴리시 단계에서

## 3. 배경 통짜 일러스트로 갈 경우 (오클루전 포기)
- 위치브룩처럼 "레이어된 씬"이 아니라 **한 장 그림 + 마커**로 만족한다면:
  `GameMap.render: 'image'` + `bgImage` 경로만 지정 (이미 구현돼 있음, `web/public/images/maps/village.png` 참고).
- 이 경우 캐릭터가 건물 앞뒤로 못 가려짐. 근접 카메라 + 캐릭터 스프라이트로 어느 정도 커버.
