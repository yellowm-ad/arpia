# 마법학교 울토르 (초안 / Draft)

> **악마의 피에서 시작된 인간의 마법. 2,000년 동안 이어진 인간과 악마의 전쟁.
> 그리고 그 끝을 선택하게 되는 한 명의 마법학교 신입생.**

쿼터뷰 시점의 **턴제 RPG** 웹게임 **초안(draft)** 입니다. 마법학교 울토르에 입학한 신입생이
되어 삼원(三源) 마법을 배우고, 계약수를 길들이며, 각지를 여행합니다. 파티(주인공 + 계약수)를
꾸려 필드를 배회하는 마수와 접촉해 행동 순서 기반 턴제 전투를 벌이고, 레벨업·전직·장비·상점
시스템을 플레이할 수 있습니다.

**이 프로젝트는 완전히 오리지널 세계관입니다.** 이전 《아르피아》 관련 설정·자료는 전부
배제되었으며, 외부 팬 리메이크(GitHub의 마법학교 부활 / ReArpia 등)와도 무관합니다.

## 1. 세계관 요약 (기획서 「마법학교 울토르」 기준)

- 2,000년 전, 지옥의 악마군단이 인간계를 침공(**인마대전**). 마법이 없던 인간은 악마의
  심장에서 흘러나온 피로 최초의 마법을 얻어 반격, 악마군단을 지옥으로 쫓아낸다. 단
  **악마왕 모르스**만은 죽이지 못하고 거대한 봉인으로 가둔다.
- 500년 전, 대륙 최고의 마법사들이 두 번째 인마대전을 막을 마법사를 양성하기 위해
  **마법학교 울토르**를 설립한다.
- 세계의 마력은 **삼원(三源)** 으로 나뉜다.
  - 🔥 **화염계 — 변화**: 불 → 번개 → 빛 (에너지·변화·시간)
  - ❄️ **빙결계 — 차원**: 얼음 → 물 → 우주 (물질·공간·차원)
  - 🪨 **대지계 — 생명**: 흙 → 풀 → 어둠 (생명·죽음·존재)
- Lv.1~50. Lv.30 전후로 모르스가 부활하며, 초반의 "마법학교 RPG" 분위기가 후반부
  "인마전쟁 RPG"로 뒤집힌다. 히든/노말/배드/진 엔딩.

## 2. 실행 방법

### 방법 A — 개발 서버

```bash
npm install
npm run dev
```

`http://localhost:3000` 접속. 코드를 수정하면 즉시 반영됩니다.

### 방법 B — 정적 빌드

```bash
npm install
npm run build   # out/ 폴더에 정적 파일이 생성됩니다
cd out && npx serve .
```

## 3. 조작 방법

- 이동: `방향키` 또는 `WASD` (모바일 화면에서는 우하단 D-Pad)
- NPC와 대화: 가까이 다가가면 하단에 안내가 뜨며 `E` 키 또는 NPC 클릭
- 마수와 접촉하면 "전투하기 / 피하기"를 먼저 물으며, 전투하기를 고르면 턴제 전투가 시작됩니다
- 우상단 아이콘: 가방 / 내 정보 / 파티 / 환경설정

## 4. 1차 구현 범위

| 영역 | 현황 |
|---|---|
| 삼원 3계통 (화염/빙결/대지) | 구현. `lib/constants.ts`의 `ELEMENT_META` — 각 계통의 3단계 각성(불→번개→빛) 포함 |
| 전직 5등급 (Lv 1/10/20/30/40) | 구현. 표시 직함은 계통별로 다름(`jobTitle()`). 예: 불 견습생 → 번개 술사 → 빛의 마도사 |
| 계통별 스킬 | 기획서 §14~22의 핵심 스킬을 데이터화(`lib/mock-data.ts`의 `SKILLS`). 전직 시 자동 습득 |
| 행동 순서 기반 턴제 전투 | 구현. `lib/battle-engine.ts` — TU(대기 게이지) 방식, 상태이상 9종 |
| 전투 액션 | 공격 / 스킬 / 물약·도구 / 방어 / 도망. 주인공은 매 턴 선택, 계약수는 자동 AI |
| 계약수 | 1차: 전투 동반 1마리 + 도감 8종 + 호감도 4구간 + 스킬 훈련. 진화는 추후 |
| 지역 | 시작 구역 8곳 배치 — 울토르 마법학교 / 상관 거리 / 대련장 / 기숙사 구역 / 마력공학동 / 에르디아 숲 / 아틀란티스 수로 / 폐허의 신전 |
| 맵 | 2km×2km, 200m 그리드(10×10). 숲/수로/신전에 마수 배회 |
| EXP 테이블 | 메이플스토리 200렙 기준을 50으로 환산한 곡선(`lib/exp-table.ts`). 테스트 모드 시 "마도 인형" 10마리 처치 = 1레벨 |
| 캐릭터 도트 그래픽 | 4등신 픽셀 스프라이트 + 4방향 걷기 모션(`components/game/pixel-hero.tsx`). 삼면도 팔레트 기반. PixelLab 생성 스프라이트를 `public/images/sprites/`에 넣으면 자동 사용 |
| 전투 화면 | 저장된 예시(클래식 JRPG 배틀 구도) 참고 — 초원 필드 + 하단 행동 순서 타임라인(TU) + 우측 액션 링 |

## 5. 프로젝트 구조

```
app/                     Next.js App Router 진입점
components/
  ui/                    버튼/카드/모달 등 범용 UI
  game/                  게임 화면 (world-screen, battle-screen, pixel-hero, hud, ...)
lib/
  types.ts               도메인 타입
  constants.ts           삼원 속성 / 전직 / 맵 / 지역
  mock-data.ts           스킬 / 아이템 / 마수·악마 / NPC 데이터
  exp-table.ts           EXP 테이블
  battle-engine.ts       턴제 전투 로직
  game-state.tsx         전역 상태(리듀서)
  field.ts / rng.ts      필드 마수 배치(결정론적 시드)
  pets.ts                계약수 도감 / 호감도 / 훈련
public/images/           플레이스홀더 SVG 아이콘
public/images/sprites/   캐릭터 도트 스프라이트 시트 (PixelLab 등에서 생성해 배치)
```
